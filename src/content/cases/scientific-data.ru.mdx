## Проблема

Числовые данные редко приходят готовыми к анализу: значения пропущены, встречаются выбросы, а измерения сделаны с шагом, который не совпадает с нужным. Чтобы считать, сравнивать и делать выводы, данные нужно подготовить, восстановить промежуточные значения и показать результат так, чтобы его можно было проверить.

## Моё участие

- Разработал программные инструменты на Python для импорта и подготовки наборов данных.
- Реализовал очистку и преобразование данных средствами Pandas.
- Работал с массивами NumPy и численными методами.
- Реализовал обработку числовых данных с применением методов интерполяции из SciPy.
- Построил графики Matplotlib для сравнения исходных и обработанных значений.
- Подготовил результаты анализа.

## Техническая архитектура

Обработка устроена как конвейер из отдельных шагов: загрузка → очистка → массивы → вычисления и интерполяция → визуализация → отчёт. Каждый шаг принимает и отдаёт данные в понятном формате, поэтому его можно проверить и заменить независимо от остальных.

## Особенности реализации

- **Подготовка данных.** Пропуски и выбросы обрабатываются до вычислений: интерполяция по «грязным» данным воспроизводит ошибки измерений.
- **Выбор метода.** Линейная интерполяция проста и предсказуема, кубический сплайн даёт гладкую кривую, монотонный PCHIP не создаёт ложных колебаний на резких переходах, а полином высокой степени по равномерной сетке раскачивается у краёв — эффект Рунге.
- **Проверка результата.** Исходные и восстановленные значения сравниваются на графиках и по метрикам ошибки.
- **Работа с массивами.** Вычисления выполняются над массивами NumPy целиком.

## Результат

Инструменты позволяют загрузить набор данных, очистить его, восстановить промежуточные значения выбранным методом и получить графики, на которых видно, как обработанные значения соотносятся с исходными.
