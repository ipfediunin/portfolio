# 01 · Аудит репозитория (до Stage 6)

Дата: 2026-11-04. Аудит проводился по коду, сборке и e2e-прогонам, а не по памяти.

## Проверенные факты: что было до этапа

**Маршруты и язык**

- Все страницы жили под сегментом `[lang]` (`/ru/...`, `/en/...`); `src/proxy.ts` перенаправлял `/` по `Accept-Language`. Был переключатель языка в шапке и мобильном меню.
- `sitemap.ts` выдавал каждую страницу дважды, с `hreflang`-альтернативами и `x-default`.
- Раздел технологий назывался `/stack`, отдельных страниц для работодателей, заказчиков, услуг и privacy не было.

**Контент и конверсия**

- Контакты в `src/content/site.ts` — заглушки на `example.com` (email, GitHub, LinkedIn, Telegram). На странице контактов email-карточка рендерилась всегда, даже с заглушкой.
- CTA главной: «Explore projects» и вторая кнопка вела в playground (`/architecture`), а не к предложению работы.
- Кейсы: 9 опубликованных, у каждого своя модель-мини-город; структура истории: Problem / My part / Technical architecture / Implementation details / Result. Различие «конкретный проект / обобщённый опыт» было только в поле `note` у двух кейсов.

**SEO**

- `metadataBase` и canonical были, но `pageMetadata` задавал `openGraph` без картинки. В Next.js дочерний `openGraph` целиком заменяет родительский, поэтому **у всех вложенных страниц, кроме главной, не было `og:image` и `twitter:image`** (проверено по HTML production-сборки).
- `robots.txt` разрешал всё в любой сборке: preview и staging индексировались бы.
- JSON-LD: только `CreativeWork` на страницах кейсов.

**Доступность**

- Токен `--color-ink-3` (#7f89a6), которым набраны подписи по всему сайту, давал контраст 3,5:1 на белом — ниже WCAG AA (4,5:1) для мелкого текста.

**Что уже было хорошо и сохранено**

- Весь смысловой контент — в DOM и SSR; canvas один на приложение, PixiJS грузится только на страницах со сценой; без WebGL остаётся SVG-постер.
- Бюджет сцены соблюдался (≤ 14 draw calls, без кадров > 50 мс при CPU ×4).
- Форма контакта: одна Zod-схема для браузера и сервера, honeypot, проверка времени заполнения, rate limit, честная ошибка доставки.

## Предположения

- Сайт не опубликован, внешних ссылок на `/ru/...` и `/en/...` нет — поэтому редиректы со старых URL не нужны (ТЗ: «если сайт ещё не опубликован, не усложняй проект ненужными редиректами»).

## Реализованные изменения (кратко; подробности — в документах 05–09)

- Маршруты перенесены в корень, сайт только на английском, `html lang="en"`, без hreflang, proxy и переключателя.
- Русский UI-словарь удалён; русские тексты контента (`{ru, en}` в `src/content`) сохранены как спящая инфраструктура — не отдаются, но и не уничтожены.
- Новые страницы: `/for-employers`, `/hire`, `/services/[slug]` (4 посадочные), `/privacy`. `/stack` → `/expertise`.
- Контакты, имя, CV, запись на созвон, аналитика — из env (`src/content/site.ts`); незаданное не показывается.
- Исправлены `og:image` на вложенных страницах, robots для не-production сборок, контраст `ink-3`.
