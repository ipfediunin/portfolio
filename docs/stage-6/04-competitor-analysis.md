# 04 · Конкурентный анализ

Дата: 2026-11-04. Разобраны два личных сайта, найденные в выдаче по запросам о независимых Python/AI-разработчиках, и тип страниц, которые занимают коммерческую выдачу. Страницы прочитаны, а не додуманы.

## Проверенные факты

### bdcreativesystems-star.github.io

- Ниша: RAG, дашборды и автоматизация для малого бизнеса.
- Одностраничник с якорной навигацией; демо — видео; основной CTA — email.
- Кейсы короткие, без архитектуры и роли автора; нет записи на созвон и отзывов.
- Сильная сторона: честные метки «concept» у демо и явное указание объёма работы.

### personal-website-e48.pages.dev (Nadir Belarouci)

- H1 «Turn your AI prototype into a production system» — предложение сформулировано через результат для заказчика.
- Есть Case Studies и блог; CTA «Book Free Intro Call» (Calendly).
- Есть отзывы, FAQ и процесс работы (discovery, минимальный срок 2–4 недели).
- Доверие строится на названных работодателях (Booking.com, Picnic).

### Маркетплейсы и платформы (Toptal, Arc, Upwork, Fiverr, Contra, Codementor)

- Занимают коммерческую выдачу; страница — каталог исполнителей с фильтрами, рейтингами и гарантиями платформы.

## Выводы для Runtime City (Qualitative estimate)

| Что у конкурентов                 | Что делаем мы                                                                                | Почему                                                 |

| Запись на созвон (Calendly)       | Кнопка «Book a call», когда задан `NEXT_PUBLIC_SCHEDULING_URL`                               | Короткий путь для заказчика; без ссылки кнопки нет     |
| Отзывы, названные работодатели    | Не добавляем                                                                                 | Нет подтверждённых данных — выдумывать нельзя          |

| Блог                              | Пока нет; темы статей — в 03                                                                 | Сначала запуск и данные Search Console                 |

## Предположения

- На этапе запуска у сайта не будет ни истории домена, ни ссылок, поэтому он не выиграет у маркетплейсов коммерческие запросы; его задача — конвертировать трафик из профилей и откликов.

## Реализованные изменения

- Посадочные с FAQ, процесс работы, связка кейс ↔ услуга, CTA по аудитории, booking по конфигурации.

## Нерешённые вопросы

- Отзывы клиентов — появятся, только если владелец получит и подтвердит реальные.

## Следующие действия
